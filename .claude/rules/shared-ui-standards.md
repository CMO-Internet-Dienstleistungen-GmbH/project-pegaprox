# UI Standards

How interfaces built in this project look and behave.

- No explanatory text for self-explanatory controls: no "Opens by hand …", "Written only after confirmation", keyboard tips or update intervals.
- Keep text only when it states facts the page does not show elsewhere: a path, a size, a language, data gaps, error reasons.
- Show content completely, not as summaries or collapsed sections.
- Every edit must be possible by hand; AI assistance is always the second option, never required.
- Use the available page width; do not constrain it artificially to a reading width.
- A UI change is not done on green tests alone; check it in the browser.
